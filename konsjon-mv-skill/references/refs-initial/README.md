# 初始参考（refs-initial）

> 目录名用英文是技术原因：`videos/` 里的 mp4 要用 ffmpeg 抽帧，**Windows 控制台非 UTF-8 代码页下读中文路径会失败**（见 `rules.md` §10 的「路径全 ASCII」）。

## 放什么

```
refs-initial/
├── chars/    ← 主角的「原始成品源码」（.jsx，不是图片）
└── videos/   ← 成品参考片（.mp4）
```

| 子目录 | 现有内容 | 是什么 |
|---|---|---|
| `chars/` | `PixelGirl.jsx`（316 行）、`PixelBoy.jsx` | **这是能跑的角色源码**，不是人设图。它们是 `assets/rig-template.jsx` 的抽象来源 |
| `videos/` | `22.mp4`（80s）、`jda.mp4`（61.6s） | 两个不同风格的成品：`22.mp4` 是叙事向（经验条 HUD），`jda.mp4` 是 RPG 向（爱心 HP HUD） |

## 三类文件的分工（别混）

| 文件 | 角色 | 怎么用 |
|---|---|---|
| `assets/rig-template.jsx` | **模板** | 建主角时**复制它**改配色与部件 |
| `refs-initial/chars/*.jsx` | **原始参考** | 只看不复用。用来对照「完整成品长什么样」——里面有模板删掉的部分（行李箱、双人站位、`facing="back"` 的完整实现） |
| `refs-initial/videos/*.mp4` | **风格参考** | 抽帧后看景别/运镜/转场/字幕位置/色彩，**不参与渲染** |

**禁止把 `chars/` 里的 jsx 直接当成品组件 import 进去用**——它们是特定角色的硬编码版本（发色、衣服、道具都写死），只能当参考。

## 两个成品片实测参数（抽帧核对过）

| | `22.mp4` | `jda.mp4` |
|---|---|---|
| 时长 | 80.0s | 61.6s |
| 分辨率 / 帧率 | 1920×1080 / 30fps | 1920×1080 / 30fps |
| 码率 | 2489 kb/s | 4448 kb/s |
| 像素格式 | **yuvj420p（full range）** | **yuvj420p（full range）** |
| 左上 HUD | LV.22 徽章 + EXP 进度条 | **20 颗爱心（HP，随歌递减）** |
| 右上 | 曲名 + 演唱者 | 曲名 + 演唱者 |
| 底部 | `♪ LYRIC` 对话框 | `♪ LYRIC` 对话框 |
| 关键词 | 单色（`hot:false`） | **红底高亮（`hot:true`）** |

> ⚠️ **两条实测结论要记住**：
> 1. 两条成品都是 `yuvj420p`，说明 `setPixelFormat("yuv420p")` **在实拍里没生效**（详见 `rules.md` §11 的说明）。
> 2. HUD 有两种合法形态：**经验条**和**爱心 HP**。选哪个看情绪，但都必须「随歌曲推进而变化」，不能是静态装饰。

## 使用规则

1. **两个子目录都空着是正常状态**，扫到空就跳过，不要报错。
2. `videos/` 里有视频 → **先问用户**要不要抽帧；不要默认抽（一次抽 30 张要好几分钟）。
3. 抽帧只看五件事：**景别、运镜、转场、字幕位置、色彩**。看完只说"这是像素风"等于没看。
4. 这两个目录**不进 `public/`**、不参与渲染、不占 DOM。
5. `chars/` 里的图/码**不许 `<Img>` 贴进画面**——人物必须是骨架代码画出来的，位图不能插值动作。
