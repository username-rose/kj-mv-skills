# 时间轴模型

## 一、三层结构（不是两层）

```
段落 Segment  ── 一个 Sequence，跨段由转场衔接
  └─ 场景 Scene ── 段落内的一段连续构图（可 1–3 个）
       └─ 镜头 Shot ── 最小单位，一次运镜
```

**一段里可以有多个场景。** 真实成片里有一段 741 帧塞了两个完全不同的场景，中间用白闪硬切——它们共用同一个 `Sequence`，不换段。

理解错了就会把它们拆成两个段落，结果转场层多写一次、UI 时间轴要重算。

---

## 二、两套帧号（错位第一大原因）

| 层 | 用哪个帧 | 谁管 |
|---|---|---|
| UI 壳 / 字幕 / 水印 / 跨段转场 | **全片绝对帧** | 最外层 |
| 场景内部（人物动作、粒子、段内遮罩） | **段内局部帧**（`Sequence` 内从 0 起） | 各段自己 |

```tsx
// 最外层：绝对帧
const globalFrame = useCurrentFrame();

// 段内：局部帧
<Sequence from={620} durationInFrames={154}>
  <Scene4 />   {/* 内部 useCurrentFrame() 从 0 开始 */}
</Sequence>
```

**规则**：

- 字幕、HUD、水印**绝对不能放进 `Sequence` 内**——否则逐字算法的 `- lead` 会被起点裁掉，开场固定丢帧
- 段内若需要全局帧，必须 `props` 显式传入，不许在段内重算
- 段内坐标（`start` / `end`）全部写**局部帧**

## 三、累加校验（必做）

```ts
const SEGMENTS = [
  { name: "校门口",   from: 0,   dur: 155 },
  { name: "红绿灯",   from: 155, dur: 148 },
  { name: "阴雨",     from: 303, dur: 317 },
  { name: "教室",     from: 620, dur: 154 },
  { name: "操场",     from: 774, dur: 144 },
  { name: "花海",     from: 918, dur: 42  },
];

// 校验 1：首尾相接
// 校验 2：总和 == durationInFrames
// 校验 3：每个 from == 上一个 from + dur
```

少写一个数就会出现重叠或空档，**表现为某处黑一帧**，极难定位。写个断言，一次就能查出来：

```ts
const total = SEGMENTS.reduce((a, s) => a + s.dur, 0);
if (total !== durationInFrames) throw new Error(`段落总和 ${total} ≠ 总长 ${durationInFrames}`);
SEGMENTS.forEach((s, i) => {
  const expect = i === 0 ? 0 : SEGMENTS[i - 1].from + SEGMENTS[i - 1].dur;
  if (s.from !== expect) throw new Error(`段落 ${s.name} 起点应为 ${expect}，实际 ${s.from}`);
});
```

## 四、时间轴六列表（Step 5 内部产出）

给 AI 自己当施工图用，不需要用户批：

| 行号 | 起止帧 | 段落/场景 | 句内镜头 | 转场（进/遮/离） | 情绪 |
|---|---|---|---|---|---|
| 1 | 0–155 | 段1 校门口 | zoom 1→1.25 | — | 明快 |
| 2 | 155–303 | 段2 红绿灯 | pan -140 | ColorWipe(134/155/174) | 过渡 |
| 3 | 303–620 | 段3 雨站 → 段3b 便利店 | 推近 + 雨 | ColorWipe(283/303/322) | 压抑 |

**切点必须落在歌词行边界上。** 六列表的每一行对应一句歌词，行数 = 歌词行数。

## 五、段内切点

段内换镜头有两种做法，**都挂在这个段内部**（`z 500–520`）：

| 做法 | 时长 | 实现 |
|---|---|---|
| 硬切 | 0 帧 | 直接换 `<div>`，最干净 |
| 白闪 | 2–4 帧 | 全屏白 `opacity 0→1→0` |
| 遮罩推进 | 6–8 帧 | 一道色带扫过 |

**不许用跨段转场做段内切换**（那是 15–35 帧的柔过渡，用在段内会拖节奏，而且会被下一段的转场盖住）。

---

## 六、时长规划

| 规模 | 帧数 | 建议 |
|---|---|---|
| 样品 | ~450（15s） | 2–3 个场景，必须含 1 个完整转场 |
| 常规成品 | ~1800（60s） | 6–8 个场景 |
| 长片 | >3600（>2min） | **必须分段渲染** |

分段规则（长片才用）：

1. 按**歌词行边界**切，不按秒切
2. 相邻两段**重叠一个转场**（前段多渲 25 帧）
3. **音频只在最后混一次**，不要每段带音频再 concat（会累积偏移）
4. concat 后校验总时长 == 各段帧数之和
