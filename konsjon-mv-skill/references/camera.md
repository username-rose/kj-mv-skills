# 运镜库

## 零、铁律：运镜必须写五件事

缺任何一项，AI 就会写成"整段匀速放大 1.02"——等于没动。

```
起点值 → 终点值 → origin → 时长(帧) → 缓动曲线
```

例：`zoom 1.0 → 1.8，origin 52% 66%，22 帧，Easing.out(Easing.cubic)`

**`easing` 不许省略。** Remotion 的 `interpolate` 省略 `easing` 默认就是 `linear`，也就是"生硬"。省略=线性。

**缓动分区（重要）**：

| 用途 | 允许 | 禁止 |
|---|---|---|
| 镜头/场景位移 | `inOut`、`out(quad)`、`out(cubic)`、`in(quad)` | `back`、`elastic` |
| UI 弹出（气泡/标签） | `back`、`spring` | —— |

原因：`back` 会冲过目标值再回弹 → 产生亚像素位移 → 像素边缘抖动发糊。
UI 层用 `back` 也必须包 `Math.round()`。

---

## 一、`transformOrigin` —— 比 zoom 更重要的那个参数

**origin 不是画面中心，是叙事主体。**

推近到 2.4 倍却用 `50% 50%`，人物会从画面下沿被切掉半截。origin 必须落在**你希望观众盯着的那一点**上。

| 景别 | origin | 说明 |
|---|---|---|
| 全身 | `50% 50%` | 平视全景，不推或微推 |
| 半身/看脸 | `50% 62%` ~ `52% 66%` | 落在胸口到肩之间 |
| 看手/看书 | `50% 75%` ~ `50% 85%` | 落在画面下部 |
| 看天空/看远方 | `50% 30%` ~ `50% 40%` | 落在画面上部 |
| 看画面左侧的道具 | `30% 60%` | 横向也要跟着偏 |

判断口诀：**origin 的 y 值 ≈ 主体重心在画面高度的百分比**。

## 二、五个运镜配方

### 1. `ZoomIn` 推近

```tsx
const zoom = interpolate(frame, [start, end], [1, 1.8], {
  easing: Easing.out(Easing.cubic),
  extrapolateLeft: "clamp", extrapolateRight: "clamp",
});
// 包裹层
style={{ transform: `scale(${zoom})`, transformOrigin: "50% 66%" }}
```

- 倍率：常规 `1 → 1.3`；强调 `1 → 1.8`；**半身特写 `1.8 → 2.4`**
- 时长：短促 12–16 帧，缓慢 26–40 帧
- 用途：情绪递进、唱到关键词、看清表情

### 2. `ZoomOut` 拉远

`1.8 → 1.0`，`Easing.inOut(Easing.quad)`，24–40 帧。
用途：段落收尾、揭示环境、从内心回到世界。

### 3. `Pan` 平移

```tsx
const x = interpolate(frame, [start, end], [0, -120], { easing: Easing.inOut(Easing.quad) });
style={{ transform: `translateX(${Math.round(x)}px)` }}
```

- 位移幅度：60–200px（1080p 下超过 250px 会显得赶）
- 必须 `Math.round()`，否则背景抖动
- 方向：跟人物行走方向一致，否则违和

### 4. `TiltUp` 上摇

用 `translateY` + 轻微 `scale` 组合，模拟"从地面摇到天空"。
幅度 80–200px，`Easing.inOut(Easing.cubic)`，30–45 帧。
**必须同时移动近景和远景，且倍率不同**（见视差表），否则像把整张图往上推。

### 5. `Shake` 震屏

```tsx
const sx = Math.round(rand(frame, 7) * 2 - 1) * amp;
```

- `amp` 1–4px（超过 6px 会晕）
- 只持续 4–8 帧，用于重音
- **必须用确定性随机**，不许 `Math.random()`
- 全片 ≤ 3 次，多了就廉价

## 三、半身特写三件套（这是"有电影感"的关键）

不是"把人放大"，而是三件事同时做：

1. **`zoom 1.8 ~ 2.4`** —— 只到这个区间，再大就糊
2. **`origin` 落在胸口 56%~66%** —— 落在腰（66%）显得近，落在肩（56%）显得紧
3. **情绪符号 / 汗滴 / 气泡必须挂在人物 `div` 内部** —— 挂在场景根节点的话，推近时它会留在原地，变成"贴纸"

推近后**背景必须继续视差移动**，否则画面会像一张被放大的照片。

## 四、视差倍率表（5 层）

同一场景里各层的移动速度比，用于营造纵深：

| 层 | 倍率 | 例（speed） |
|---|---|---|
| 远山 / 天空 | 1.0 | 0.05 |
| 云 | 2.4 | 0.12 |
| 中景（楼/树） | 4.4 | 0.22 |
| 地面 / 路面 | 9.6 | 0.48 |
| 前景（草/栏杆） | 13 | 0.65 |

```tsx
// 每层一份，必须画两份首尾相接防露白
translateX(${-((frame * speed) % tileWidth)}px)
```

层间差保持 2–3 倍，差距太小没有纵深，太大像分层贴纸。

## 五、镜头表（Step 5 阐述里要给出的形态）

| 镜头 | 起止 | 运镜 | origin | 曲线 |
|---|---|---|---|---|
| 1 | 0–90 | zoom 1→1.3 | 50% 50% | out-cubic / 26 帧 |
| 2 | 90–155 | zoom 1.3→1.8 | 50% 66% | inOut / 30 帧 |
| 3 | 155–310 | pan -120px + 微 zoom 1.05 | 50% 60% | inOut / 全段 |

写表比写文字可靠——一眼能看出"这一段是不是又没动"。
