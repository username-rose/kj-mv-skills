# 转场库与三时点契约

## 一、铁律

1. **转场是独立覆盖层，绝不包裹场景组件**。包裹会导致镜头缩放把转场一起缩放，直接穿帮。
2. **三时点**：`(进入帧, 遮挡帧, 离开帧)`。**遮挡帧必须严格等于下一段的切点帧**，否则出现"旧场景已走、遮挡物没盖住"的空帧。
3. **图层位置**：跨段转场 `z-index: 500`（场景 1–10 之上、UI 9999 之下）。
4. **窗口外不挂载**：`if (frame < enter || frame > exit) return null;`
5. **时长**：15–35 帧。低于 15 帧看不清，高于 35 帧拖节奏。
6. **全片主用跨段转场 ≤ 2 种（推荐 1 种贯穿）**，段内切法 ≥ 2 种。

> ⚠️ 这条和我们之前的版本相反：**变化不靠换转场种类，靠镜头和场景**。
> 每段换一种转场，结果就是花里胡哨但廉价。

统一签名：

```tsx
type Wipe = (p: { frame: number; enter: number; cover: number; exit: number }) => JSX.Element | null;
```

## 二、跨段 vs 段内的分工

| | 跨段 | 段内 |
|---|---|---|
| 目的 | 换场景、换情绪 | 换镜头、换构图 |
| 实现 | 独立转场层（`z 500`） | 遮罩 / 硬切（`z 500–520`，**挂在场景内部**） |
| 时长 | 15–35 帧，柔 | 4–8 帧，硬 |
| 数量 | 全片 5–7 次 | 每段 0–2 次 |

**段内遮罩必须挂在场景层内部**，否则会被下一段的转场盖住，出现"两层遮罩打架"。

## 三、转场库

### ★☆☆ 低成本（首选）

**1. `ColorWipe` 单色柔光淡入淡出（主力，跨段默认）**

全屏铺一层纯色，升上去再降下来，中途完成换场景。**无黑屏**，比白闪柔和。

```
三时点：(from, peak, to)，peak = 下一段切点
时长：30–35 帧（升起 13–15 帧 / 落下 17–20 帧）
曲线：Easing.inOut(Easing.quad)
```

**颜色取法**：取**下一段场景的 `sky2`，向白色混 40%**。

```ts
const hex = (c) => parseInt(c.slice(1), 16);
const mixWhite = (c, k = 0.4) => {
  const n = hex(c);
  const r = Math.round(((n >> 16) & 255) * (1 - k) + 255 * k);
  const g = Math.round(((n >> 8) & 255) * (1 - k) + 255 * k);
  const b = Math.round((n & 255) * (1 - k) + 255 * k);
  return `rgb(${r},${g},${b})`;
};
```

**为什么不用 `FlashCut`**：2 帧纯白是"闪"，会打断情绪；`ColorWipe` 是"化"，适合书页翻过、季节更替这类软过渡。

**2. `FlashCut` 像素硬切 + 闪白**

切点帧插 2 帧纯白（`#FFFAF0`），无位移。时点 `(146, 150, 154)`，切点 152。
用途：踩重音、段落内快速切换。全片 ≤ 3 次。

**3. `StepSlide` 阶梯平移**

以 `8px` 为单位、每 2 帧跳一格。`const step = Math.floor(frame / 2) * 8;` **必须取整**。
时点 `(140, 152, 164)`。用途：具象化模式的中性过渡。

### ★★☆ 中等成本

**4. `CloudWipe` 云层遮挡**

像素云或掠过的大道具从一侧盖住全屏。遮满时切底层。
实现：`translateX(-120%) → 0 → 120%`，遮挡帧必须完全覆盖。

**5. `BlockWipe` 大方块覆盖**

`120×120` 大块网格（16:9 约 `8×5 = 40` 块）逐列覆盖。
**严禁逐像素块渲染**（16×16 铺满 = 8160 节点，必崩）。或直接用单层 CSS `clip-path` 推进。
用途：踩重音，块的出现节奏对齐鼓点。

**6. `CrtOff` CRT 关机**

纵向压成亮线 → 缩成点消失 → 黑屏 → 新场景亮起。
实现：旧场景 `scaleY(1 → 0.01)` 配 `brightness` 拉高；新场景延迟 8 帧再 `scaleY(0.01 → 1)`。
用途：情绪转折、回忆结束。

**7. `CurtainSplit` 幕布分屏**

上下两半 `clip-path` 分别 `translateY(-100%)` / `translateY(100%)`。
时点 `(136, 152, 168)`。用途：由静到动、气势转换。

**8. `ObjectPass` 道具入画**

道具飞向镜头放大到盖满全屏，飞走时已换场景。`scale(1 → 18)`，`opacity` 保持 1。
用途：故事流，可复用剧情道具（纸飞机、车票、书）。

### ★★★ 高成本（谨慎，全片 ≤ 1 次）

**9. `PixelDissolve` 像素溶解**

单层 `<svg>` 用 `mask`，方块按 `rand(i, 3) * 12` 延迟消失。**必须确定性随机**。
用途：情绪断裂、梦境。

**10. `GlitchShift` 故障平移**

两份场景副本 `mix-blend-mode: screen`，`translateX(±4px)` 错位，抖动用 `Math.round(rand(frame, 9) * 6 - 3)`。
注意：`mix-blend-mode` 是贵操作，低配时禁用。

**11. `IrisWipe` 光圈缩放**

`clip-path: circle(${r}% at 50% 50%)`，`r` 按帧增长。
像素感靠量化：`r = Math.floor(p * 12) / 12`。
用途：聚焦、回忆入口、结尾收束。

## 四、情绪 → 转场映射

| 情绪段落 | 首选 | 备选 |
|---|---|---|
| 明快、日常、叙事 | **ColorWipe** | 云层遮挡 |
| 压抑、雨、低落 | CRT 关机 | 溶解 |
| 转折、顿悟 | 幕布分屏 | CRT 关机 |
| 高潮、踩重音 | 大方块覆盖 | 闪白 |
| 回忆、梦境 | 光圈缩放 | 溶解（浅） |
| 结尾、收束 | **ColorWipe** / 光圈缩放 | CRT 关机 |
