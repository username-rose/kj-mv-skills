# 角色骨架规范

## 一、两套画法，别混用

| 对象 | 画法 | 原因 |
|---|---|---|
| **主角 / 需要动作的人物** | **骨架**（部件表 + 关节 + pose 函数） | 需要连续插值，ASCII 做不到 |
| 静态道具、远景小人、图标 | ASCII 字符网格（见 `components.md`） | 一格一 rect，最省事最可控 |

**主角绝对禁止用 ASCII 单帧。** 那样走路只能两帧来回切，一动就像纸片。

---

## 二、网格与坐标系

- **10 格宽 × 20 格高**，`viewBox="0 0 100 200"`，`CELL = 10`
- 头部 7 行（y 0–6），身体 13 行（y 7–19）
- 所有部件坐标用**格**为单位（整数），渲染时乘 `CELL`
- 材质比例：约 **1:2**（宽 10 格 / 高 20 格）

## 三、四个关节（世界坐标，单位 = 格 × CELL）

```js
const JOINT = {
  armL: { x: 10, y: 70 },   // 左肩
  armR: { x: 90, y: 70 },   // 右肩
  legL: { x: 40, y: 130 },  // 左髋
  legR: { x: 60, y: 130 },  // 右髋
};
```

**关键理解**：部件（手臂/腿）画在**自己的绝对位置**上（比如左臂画在 x=0 附近），然后整体绕关节旋转。所以改部件时不要动关节，改 pose 时不要动部件。

```js
const rot = (deg, j) => `rotate(${deg.toFixed(2)} ${j.x} ${j.y})`;
```

## 四、部件表结构

每个部件是一组 rect：

```js
const ARM_L = [{ x: 0, y: 7, w: 2, h: 5, fill: C.shirt }];
const ARM_L_HAND = [{ x: 0, y: 11, w: 2, h: 1, fill: C.skin }];
```

部件清单（缺一不可）：

| 部件 | 说明 |
|---|---|
| `HEAD` | 正面（含五官层） |
| `HEAD_BACK` | 背面（整片头发，无五官） |
| `TORSO` | 躯干（含衣摆、腰带） |
| `ARM_L` / `ARM_R` | 上臂+小臂（同一组） |
| `HAND_L` / `HAND_R` | 手（1 格皮肤色） |
| `LEG_L` / `LEG_R` | 腿（含鞋） |
| `SIT_LEGS` | 坐姿专用腿（不参与旋转） |

**渲染顺序（从下到上）**：手臂 → 腿 → 躯干 → 头。手臂在躯干后面，这样手臂摆动时不会被身体挡住边。

## 五、动作库（11 个，直接抄）

`b` / `p` 均为 `Math.sin((frame / N) * Math.PI * 2)`，N 见各行。角度单位=度。

| 动作 | 公式 | 用途 |
|---|---|---|
| `idle` | `b=sin(frame/19)` → `armL=b*3.5, armR=-b*3.5, bob=-\|b\|*0.4` | 待机呼吸 |
| `walk` | `b=sin(frame/16)` → `armL=b*30, armR=-b*30, legL=-b*24, legR=b*24, bob=-\|b\|*1.5` | 行走 |
| `pocket` | `b=sin(frame/20)` → `armL=-5+b*3, armR=5-b*3, legL=-b*28, legR=b*28` | 插兜走 |
| `pull` | `b=sin(frame/18)` → `armL=10+b*5, armR=-30+b*3, legL=-b*20, legR=b*20` | 拉行李箱 |
| `throw` | `b=sin(frame/10)` → `armR=146+b*3, armL=-12-b*2, legL=-7, legR=7, bob=-1.5` | 抛掷 |
| `trouble` | `b=sin(frame/15)` → `armR=168+b*1.5, armL=10+b*2, bob=2+\|b\|*0.5` | 扶额烦恼 |
| `cover` | `b=sin(frame/9)` → `armL=172+b*3, armR=-172-b*3, bob=2.5+\|b\|*0.6` | 抱头躲雨 |
| `wipe` | `b=sin(frame/8)` → `armL=166+b*8, armR=-8, bob=0.8` | 擦汗 |
| `kick` | `legR=-72, legL=14, armL=34, armR=28, bob=-4` | 踢腿（静态） |
| `sit` | `b=sin(frame/24)` → `legL=-84, legR=-84, armL=-14+b*1.2, armR=14-b*1.2, bob=7+b*0.4` | 坐姿 |
| `shy`(mood) | `b=sin(frame/20)` → `armL=-8+b*2, armR=8-b*2, bob=1.2+\|b\|*0.5` | 害羞 |

`bobY` 最后要换算：`translateY(${bobY * (height / 200)}px)`，并包 `Math.round()`。

**默认参数取 0**（`armL/armR/legL/legR/bobY` 全部为 0），只有动作分支里覆盖。

## 六、表情层与遮挡检查（改部件时必查）

五官在头部部件里分三层，**顺序不能乱**：

1. 脸底色（3 行皮肤色）
2. 眼睛（1×1，位置 x=3 与 x=6，y=3）
3. 腮红（1×1，x=3/x=6，y=4）与嘴（2×1，x=4，y=5）

`mood = "shy"` 时：眼睛改深色横线、腮红换更红的色、嘴换色。

> ⚠️ **加眼镜、加刘海、加帽子时，必须检查是否压住眼睛和嘴那两格。**
> 压住了就会出现"表情永远不变"的主角，而且极难发现原因（因为静态图看着正常，动起来才发现）。

## 七、身高与比例

```js
// 不要写死 px
const h = Math.round(height * 0.30);   // 占画面高度 30%（28%–33% 区间）
```

1080p 下约 **302–356px**。太小会显得远、表情看不清；太大会顶掉字幕框。

## 八、多主角

- `heroA.tsx` / `heroB.tsx` / `heroC.tsx` 必须**共用同一网格（10×20）与同一套色板槽位**，否则同框时头和身体比例对不上。
- 双人同框：站位差至少 3 格，后侧人物 `opacity` 可降 0.9 或整体缩到 0.92（近大远小）。
- 牵手/互动：只允许改 `pose` 的角度值，**不许改关节坐标**——改关节会破坏两人比例。

## 九、三级修改（封版后还能改什么）

| 级别 | 改什么 | 代价 | 是否算封版失效 |
|---|---|---|---|
| **1 · 改色** | `PALETTE` 里的 hex | 重渲静帧，30 秒 | 否 |
| **2 · 改部件** | 增删 rect（眼镜、发型、鞋型） | 重渲静帧 + 查表情遮挡 | 否 |
| **3 · 改骨架** | `JOINT` / `CELL` / 头身比 | 全片重渲 + 动作重新标定 | **是** |

**颜色必须集中在文件顶部的 `PALETTE` 对象里**，场景文件不许出现任何主角颜色字面量。否则改一次衣服要动十个文件，改到第三次就没人愿意改了。

## 十、必须提供的静帧（Step 4 给用户看）

1. 正面站立（`idle`，第 0 帧）
2. 背面站立（`facing="back"`）
3. 一个动作（`walk` 第 8 帧）
4. 一个表情（`mood="shy"`）

四张一起给，用户才能判断"像不像"。
