# 道具库（索引 + 详情）

## 一、怎么用（两层结构）

这个库会越来越长，**不要每次都从头读**：

1. **先读索引表**（第二节）——每项一行，挑出你要的 3–5 个
2. **再往下读详情**（第三节）——只看挑中的那几个

详细度原则：**只给"构成要点"，不给完整坐标。** 抄代码会抄错坐标，照要点重画反而对。

所有道具都是静态的，用 ASCII 网格或 `<rect>` 直接拼（见 `components.md`）。
**需要动作的人物不在这里，用 `characters-rig.md` 的骨架。**

## 三、详情（构成要点）

### 云
3–5 个白色矩形交错堆叠，宽度不等；底沿加一条浅灰矩形作影（`sky` 向黑混 20%）。
**云的移动必须视差**：speed 0.10–0.20 px/帧，画两份首尾相接。

### 树
树干 `8×32` 棕矩形；树冠 3 个 `24×24` 绿色矩形呈品字形（中间高、两侧低半格）。
三阶色：主绿 / 亮绿（左上 1 格）/ 暗绿（右下 1 列）。

### 山
`<polygon>` 三角，纯色填充，边缘做成阶梯锯齿（每 4px 一阶）。
三层山：越远越浅（`mid2` → `mid1` → `outline`），倍率 1 : 2.4 : 4.4。

### 水坑
深蓝横向长条（`ground` 向黑混 40%），宽 40–120px；上叠 2–3 条 1px 高白线作反光，长度递减。
涟漪：`opacity` 按 `sin(frame/30 + i)` 波动，不用做几何变形。

### 草丛（前景必备）
底部一条棕色细条作土；上方 5–8 根绿色尖矩形，高度不等（8–20px），
每根按 `sin(frame/12 + i * 0.7)` 摆动 ±3px，**必须包 `Math.round()`**。

### 高楼
深灰大矩形主体；顶部一条 5px 亮色作"女儿墙"；窗户用 `<pattern>` 平铺 `16×22` 小矩形，
间距 `38×44`；按 `rand(i, 7)` 熄灭约 60%（`opacity` 0.45）。

### 路灯
深灰竖杆（`6×90`）+ 顶部横臂（`20×6`）+ 亮黄灯块（`10×8`）；
光晕用 `radial-gradient`（`glow` 色，半径约灯块 6 倍，alpha 0.35），**不要 `filter: blur`**。

### 红绿灯
黑色竖框（`14×40`）+ 内部 3 个 `8×8` 色块（红/黄/绿）；
亮起的那颗 `opacity 1`，其余 `0.35`；切换周期约 90 帧。

### 校车
黄车身（`120×44`）+ 顶部深色窗带（每窗 `14×12`，等距 5 个）+ 双黑轮（`14×14`）+ 深色底边；
车身中部一条白色细条写 `SCHOOL BUS`（用 `PIXEL_FONT`，字号 10）。

### 便利店招牌
亮色横条（`90×26`，`accent` 色）+ 内部 `24H` 三字符（`PIXEL_FONT`）；
灯管闪烁：`opacity = rand(Math.floor(frame/6), 3) > 0.15 ? 1 : 0.55`。

### 斑马线
等距白条 6–8 条，宽度向上（远处）递减（透视收窄），间距同减。

### 行李箱
箱体 `30×54`（`#d4763f`）+ 顶亮边 4px（`#e8a06a`）+ 左暗边 4px（`#b05c2c`）+ 底暗边 4px；
两条横纹 `13×3`；双轮 `9×6` 深色 + 中间 1 格高光；拉杆用 `<polygon>`（细长斜四边形）。

### 伞
伞面：阶梯弧（从左到右 7 块，高度按 `[2,4,5,6,5,4,2]` 排）；
伞柄：竖线 + 底部弯钩（2 格 L 形）；伞尖：顶部 1×2 深色块。
**伞要挂在人物 `div` 内部**，否则推近时伞不跟着走。

### 课桌
桌面 `60×8`（浅木色）+ 两侧桌腿 `6×30`（深木）+ 桌上摊开的书（白矩形 + 中线 + 两行灰线）。

### 书架
`<pattern>` 竖条（宽 10–16，色相在 3–4 个值里轮换）铺满；每层加一条 4px 深色隔板。

## 四、兜底规则

索引表里没有的物件 → **不许找图，也不许说做不了**：

1. 拆成 3–5 个基础几何（矩形 / polygon / 圆用阶梯块）
2. 至少 2 阶色 + 1 个描边色
3. 尺寸落在整数格上
4. 拼装方案写进导演阐述给用户确认
5. 确认后**写进项目的 `docs/skill-extras.md`**（**本文件只读，不许改**），交付时提醒用户可手动合并

## 五、自检

- [ ] 每个道具都用了 `<rect>` / `<polygon>`，没有 `<Img>`？
- [ ] 复杂物件有 ASCII 网格或明确尺寸？
- [ ] 至少 2 阶色（主色 + 暗部）？
- [ ] 窗户/书脊用了 `<pattern>`？
- [ ] 雨滴/星点/草没用 pattern（它们要独立相位）？
- [ ] 要动的东西都挂在人物 `div` 内部？
