# 歌词特效（三正交维度 + 6 个预设）

## 零、三态基线（所有档位共用）

| 状态 | 样式 |
|---|---|
| 未唱 | `ui_shell.dim`（暗灰） |
| 已唱 | 白 + 硬阴影 `3px 3px 0 rgba(0,0,0,0.55)` |
| 关键词亮起 | `ui_shell.hot` 底色 + 纯白字 + `0 0 0 3px` 浅色光环 |

**逐字亮起帧**：

```
hitAt = start + (i * (end - start) / N) - CONFIG.lead
```

- `N` = 本句字数，`i` = 当前字索引，`lead` 默认 4（标定方法见 `audio-sync.md`）
- **均分只是兜底**：句中若有明显停顿、拖长音、或关键词组需要整组同时亮，必须手工给 `hits` 逐字时间数组
- 每字**固定格宽**（`CH`），禁止 flex 自适应——否则逐字变色时整句宽度变化会抖动

## 一、三个正交维度（别再混成一个档位名）

之前的版本把「呈现方式 + 是否高亮」揉进了一个 `plain` 里，结果实现时总有一个参数是死的。拆开：

| 维度 | 配置项 | 取值 |
|---|---|---|
| **呈现方式** | `lyricMode` | `instant`（整句一次出现）/ `perChar`（逐字弹出）/ `karaoke`（遮罩横扫） |
| **强调方式** | `hot` | `false`（只变色）/ `true`（关键词放大 1.2–1.5 + 红底） |
| **容器** | `lyricBox` | `bare`（无框）/ `dialog`（对话框）/ `bubble`（气泡） |

三者互相独立，任意组合。但有 6 个组合是经过验证的，优先用它们：

| 预设名 | 组合 | 观感 | 适合 |
|---|---|---|---|
| `plain` | instant + hot:false + bare | 干净硬切 | 主歌、低配、默认 |
| `typewriter` | perChar + hot:false + bare | 逐字生成 | 叙事、独白 |
| `hotScale` | instant + hot:true + bare | 关键词炸 | 副歌顶点（全片 ≤3 句） |
| `dialog` | perChar + hot:false + dialog | RPG 对话 | 故事流整片 |
| `float` | perChar + hot:false + bare + 正弦 | 漂浮 | 轻快、回忆 |
| `karaoke` | karaoke + hot:false + bare | 跟随跟唱 | 慢歌长句 |

`config` 里写三个字段，不要写一个 `lyricFx` 字符串。

## 二、`dialog` 具体规格（实测值）

| 项 | 值 |
|---|---|
| 左右留白 | 各 `20%`（框宽 = 画面 60%） |
| 底部 | 距 UI 壳层内沿 `4px` |
| 高度 | 画面高度的 `16%`（1080p ≈ 173px） |
| 边框 | `5px` 白边 + `0 0 0 4px` 外描边 + `inset 0 0 0 3px` 内影 |
| 底色 | `ui_shell.dialogBg` |
| 左上标签 | 宽约 140、高 40，**上沿超出边框一半**（`top: -22px`），内写 `♪ LYRIC` |
| 右下光标 | 三角方块，`Math.floor(frame / 10) % 2 === 0 ? 1 : 0.15`（10 帧一周期） |

## 三、字数溢出（不处理会撑破框）

```
框内可用宽 = 画面宽 × 0.60 = 1920 × 0.60 = 1152
单字占位   = CH + 10（左右各 5px 间距）
最大字数   = floor(1152 / (CH + 10))
```

`CH = 46` 时 → 最多 **20 字**。

超过的处理顺序：

1. **降 `CH`**：`CH = floor(1152 / N) - 10`，字号跟着变 `CH - 4`
2. 仍不够 → 允许断成两行（两行都居中，行高 = `CH + 6`）
3. **绝对不许缩字号却不动 `CH`**——会破坏基线，字看起来会跳

## 四、片尾死线（这条栽过）

```
FADE_FROM = 最后一句歌词的 end 帧
```

**不是** `durationInFrames - N`。写成后者时，最后一句会被渐黑吃掉半个字。

```ts
// 死命令：唱完再黑
const FADE_FROM = LINES[LINES.length - 1].end;
```

- 渐黑时长：约 42 帧（1.4 秒）
- 歌词框淡出：最后一句 `end` 之后 **10 帧内**完成
- 片名/署名出现：渐黑完成后再 +8 帧

---

## 五、入场与退场

- 入场动作 **≤ 10 帧**；持续型动画（漂浮、横扫）不受此限
- 位移缩放用 `interpolate` + `Easing.out(Easing.quad)`；容器弹出可用 `spring`
- 换句时整行从上方滑入 `14px` + `opacity 0.25 → 1`，8 帧 ease-out
- **不是每句都滑入**：`instant` 模式应当硬切（无位移），否则全片在晃

## 六、自检

- [ ] 三个维度是分开配的，不是一个档位字符串？
- [ ] 每字固定格宽，没用 flex 自适应？
- [ ] 字数没超过 `1152 / (CH + 10)`？
- [ ] `FADE_FROM` 取的是最后一句的 `end`，不是 `duration - N`？
- [ ] 关键词高亮全片 ≤ 3 句（`hot:true` 时）？
- [ ] 行时间有停顿/拖长时，给了 `hits` 而不是均分？
- [ ] 退场在最后一句唱完之后？
