# 情绪符号（Emotes）

## 零、为什么必须用符号，而不是"震动"

"每句歌词 1 个视觉重音"这个要求，最容易的落地方式是**画面抖动**——但 AI 会因此每句都抖，观感就是"一直在抖"。

真实成片的做法是：**大部分重音交给情绪符号**，震动只用在全片不超过 3 处。

优先级：**情绪符号 > 道具入画 > 关键词变色 > 画面震动**

---

## 一、气泡容器规格（实测值，直接抄）

| 项 | 值 |
|---|---|
| 底色 | `#fdfaf0`（米白，不用纯白，纯白刺眼） |
| 边框 | `7px` 实线 `#221c2c`（近黑带紫，比纯黑柔和） |
| 硬阴影 | `8px 8px 0 rgba(0,0,0,0.45)`（零模糊） |
| 圆角 | `0`（像素风不圆角） |
| 内边距 | 10–14px |
| 最小尺寸 | 44 × 44 |
| 三角尾 | 底宽 **20**、高 **20–32**（按距离主体远近调），与气泡同色同边框，用两个 `<polygon>` 或几个 `<rect>` 堆成阶梯 |
| 层级 | 挂在**人物 `div` 内部**，`z-index` 高于人物但低于字幕 |

```tsx
<div style={{
  background: "#fdfaf0",
  border: "7px solid #221c2c",
  boxShadow: "8px 8px 0 rgba(0,0,0,0.45)",
  padding: "10px 12px",
  minWidth: 44, minHeight: 44,
  display: "flex", alignItems: "center", justifyContent: "center",
}}>
```

## 二、9 个基础符号（点阵画法）

每个符号用 **12×12 或 16×16 网格**，纯 `<rect>` 拼。下面给的是构成要点，不是完整坐标——按网格自己排，保证边缘落在整数格。

| # | 符号 | 构成 | 主色 | 用在哪 |
|---|---|---|---|---|
| 1 | 怒气 💢 | 4 条短线从中心向外放射（阶梯状，不是斜线） | `#e8443f` | 被冒犯、烦躁 |
| 2 | 汗滴 💧 | 上尖下圆的水滴：3 层阶梯收窄 + 底部 1 格高光 | `#5fc8e8` | 紧张、赶时间、尴尬 |
| 3 | 惊叹 ！ | 竖条 2 格宽 + 底部 1 格方块，中间断开 1 格 | `#ffd93d` | 突然、惊喜 |
| 4 | 疑惑 ？ | 上方问号弧（用 5–6 个方块排 L 形）+ 底部 1 格 | `#ffd93d` | 没听懂、迟疑 |
| 5 | 微笑 🙂 | 2×1 眼睛 ×2 + 3 格宽弧形嘴（中间下沉 1 格） | `#221c2c` | 释然、温柔 |
| 6 | 叹气 | 3 条 1 格宽的波浪状短线（相位错开） | `#8a84a8` | 无奈、疲惫 |
| 7 | 失落 😞 | 眼睛向下斜（2 格阶梯）+ 嘴角下垂 | `#8a84a8` | 沮丧、失望 |
| 8 | 墨镜 | 2 个 4×3 深色方块 + 中间 1 格桥 + 上沿 1 格高光 | `#221c2c` | 酷、故作镇定 |
| 9 | 无语 … | 3 个 1×1 方块，等距水平排列 | `#8a84a8` | 沉默、尴尬 |

**共同规则**：符号本身不带框（框由气泡提供）；线宽至少 1 格，1 格在 1080p 下约 4px，再细就看不见。

## 三、弹出动画（spring，允许）

```tsx
const s = spring({
  frame: frame - bornAt,
  fps,
  config: { damping: 8, stiffness: 200 },   // damping 8–9 / stiffness 160–210
});
// scale 从 0.4 → 1，同时 opacity 0 → 1
```

- **入场** ≤ 10 帧完成（spring 大约 8–12 帧稳定）
- **停留**：跟着歌词行的剩余时长
- **退场**：6 帧内 `scale → 0` + `opacity → 0`，用 `Easing.in(quad)`
- 出场位置：人物头部**右上方**（默认），空间不够时换左上方，别压脸
- `transform` 的位移要 `Math.round()`，scale 不用

## 四、密度控制（最容易做坏的地方）

**全片符号数量 ≤ 10 处**（80 秒片子的实测密度是 9 处）。

- 均匀分布，**不要连续两句都用**
- 只在情绪转折、关键词、反讽处用
- 副歌可以密一点（每句最多 1 个），主歌隔句
- 同一个符号**全片不要重复超过 2 次**

超了这个密度，观众会觉得"满屏贴纸"，反而廉价。

---

## 五、与歌词的关系

符号出现时机 = 该句的**关键词亮起帧**（比 `hitLead` 再晚 2–4 帧，让眼睛先看到字再看到符号）。

如果一句里有多个关键词，只给**情绪最强的那一个**配符号，其余只变色。
