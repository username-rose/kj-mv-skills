# 静态物件画法 · UI 壳层 · 水印

> **本文件只管"不会动的物件"。**
> 主角和需要动作的人物 → 用 `characters-rig.md` 的骨架，不许用 ASCII 单帧。

---

## 一、ASCII 网格法则（静态道具唯一画法）

1. **每行字符数必须完全相同**，否则点阵错位。注释一律写在代码块**外面**。
2. `.` 表示透明，其余字母表示颜色，图例写在块外。
3. 每个字符渲染成一个 `<rect>`，边长 = `渲染尺寸 / 网格宽度`。
4. 每个物件至少 **2–3 阶色**：主色、暗部、（可选）亮部。
5. 网格坐标一律整数，渲染时用 `viewBox` 放大。

**渲染器**：

```tsx
const rows = MAP.length, cols = MAP[0].length;
const px = size / cols;
MAP.map((row, r) =>
  row.split("").map((c, i) =>
    c === "." ? null : (
      <rect key={`${r}-${i}`} x={i * px} y={r * px} width={px} height={px} fill={LEGEND[c]} />
    )
  )
);
```

**云朵示例（12 宽 × 6 高）**

图例：`.` 透明 ｜ `C` 云白 ｜ `D` 云影

```text
....CCCC....
..CCCCCCCC..
.CCCCCCCCCC.
CCCCCCCCCCCC
CCCCCCCCCCCC
.DDDDDDDDDD.
```

## 二、物料速查（构成要点，不是固定坐标）

> 窗户 / 砖墙 / 书脊 / 网格类**必须用 SVG `<pattern>` 平铺**，1 个节点代替 40+ 个 `<rect>`。
> **但雨滴/星点/落叶/萤火虫要独立相位，不能用 pattern**，它们允许独立节点。

| 物件 | 构成要点 |
|---|---|
| 云朵 | 3–5 个交错白色大矩形，底沿加一条浅灰矩形作影 |
| 树木 | 棕色竖矩形树干 + 3 个 24×24 绿色矩形呈品字形堆叠树冠 |
| 高楼 | 深灰大矩形主体 + `<pattern>` 铺亮黄窗户（按 `rand` 随机熄灭一部分） |
| 路灯 | 深灰竖杆 + 顶部横臂 + 亮黄灯块 + `radial-gradient` 光晕（不用 box-shadow） |
| 雨滴 | 2×8 斜向白色矩形，`rand` 分布，`translateY` 循环下落 |
| 雪花 | 1×1 / 2×2 白点，下落时叠加 `sin` 左右飘 |
| 水坑 | 深蓝横向长条 + 2–3 条极细白色水平反光线 |
| 草丛 | 底部棕色细条 + 上方数根绿色尖矩形，`sin(frame/12 + i)` 错相位摆动 |
| 车流 | 车身 3–4 色矩形叠加，2 个深色小方块作轮，夜间加前后灯 |
| 鸟群 | 2 帧切换的 `V` 形 3 像素折线，整组沿斜线移动 |
| 花丛 | 绿色茎 + 顶端 3×3 彩色方块，成片时花色随机但**种子固定** |
| 书脊 | `<pattern>` 竖条平铺，色相在 3–4 个值里轮换 |
| 行李箱 | 30×54 箱体 + 4px 顶亮边 + 4px 左暗边 + 横纹 + 2 个轮（拉杆用 polygon） |

## 三、UI 壳层（"游戏机感"的骨架）

**层级**：独立 `div`，`z-index: 9999`，**不参与任何镜头平移与缩放**。
必须是场景与转场的**兄弟节点**——父级有 `transform` 会把 `z-index` 困在层叠上下文里。

三层嵌套（厚度 = 画面短边的 **4.6%**，1080p 约 **50px**）：

| 层 | 写法 |
|---|---|
| 机身层 | `inset: 0`，边框宽 = 厚度，色 `ui_shell.bg` |
| 外沿白线 | `inset: 6px`，边框 `4px`，色 `ui_shell.border` |
| 内沿白线 | `inset: 厚度 - 4px`，边框 `5px`，色 `ui_shell.border`，加 `inset 0 0 0 3px ui_shell.bg` 内影 |

附加装饰：

- 四角 `22×22` 方块，`shellHi` 与 `border` 交替
- 底部居中 `12×12` 指示灯，`Math.floor(frame / 20) % 2` 呼吸

**左上 HUD（两种实测形态，选一）**

> HUD 必须是**随歌曲推进而变化**的，不能是静态装饰。这是"高级感"的主要来源。

**形态 A · 经验条**（叙事向）

等级徽章 96×96（`5px` 白边 + `0 0 0 5px` 外环 + `8px 8px 0` 硬影）+ 进度条（宽 226、槽高 17、20/40/60/80% 四道刻度）。
进度值 `pct = 12 + (frame / totalFrames) * 76`，另加 `sin(frame/7)` 呼吸的 "EXP UP" 文字。

**形态 B · 爱心 HP**（RPG 向）

一排 20 颗 8×8 像素心，随歌曲推进逐颗减少：
`alive = Math.ceil(20 - (frame / totalFrames) * 12)`（全片掉 12 颗，留 8 颗）
每颗心 2 阶色（亮红 + 暗红描边），掉血时那颗留 6 帧"闪白"再消失。

**右上**：曲名 + 演唱者，`PIXEL_FONT`，白色，右侧留足壳层厚度。

## 四、水印

- 文字：`CONFIG.watermark.text`（默认 `@konsJon`）。`on === false` 时**整块不渲染**，不留空容器。
- 字号：画面高度的 **1.6%–2.0%**（1080p ≈ 18–22px）。4% 太抢画面。
- 透明度：`0.55 ~ 0.87` 之间按 `sin(frame / 40)` 缓慢呼吸
- 位置：右下角 `right: 4%`、`bottom: 4%`（在壳层内侧安全区，别压在边框上）
- 可加：左侧 3 个 `8×8` 色块作 logo
- 层级：`z-index: 999`，在水印容器内最高，**不参与镜头运动、不被转场覆盖**
